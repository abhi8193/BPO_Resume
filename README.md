Professional Resume & Portfolio

This repository contains the files for Abhishek Sadh's professional resume, featuring a modern web-based portfolio and a classic ATS-friendly PDF.

📂 Repository Structure

index.html: The main web-based resume. Built with HTML and Tailwind CSS.

Abhishek_Sadh_Pic.jpg: Your professional profile picture used in the web resume.

Abhishek_Sadh_Classic_CV.pdf: The minimal, ATS-optimized version of the resume.

🛠️ How to Edit & Update

1. Updating the Web Resume

To change text, contact details, or job descriptions, open index.html in any text editor.

Tailwind CSS: Styling is handled via utility classes within the HTML tags.

Download Link: Ensure the href attribute in the "Download Classic CV" button matches the exact filename of your PDF.

2. Updating the Profile Picture

Replace the Abhishek_Sadh_Pic.jpg file with a new image.

Important: Keep the filename exactly the same to avoid broken links, or update the <img> tag in index.html.

3. Updating the Classic PDF

The "Classic" version was generated using LaTeX. If you need to make structural changes:

Use the provided LaTeX code to generate a new PDF.

Download the new PDF.

Rename it to Abhishek_Sadh_Classic_CV.pdf and upload it here to replace the old version.

🚀 Hosting on GitHub Pages

This resume is designed to be hosted for free on GitHub Pages:

Go to repository Settings.

Navigate to Pages on the left sidebar.

Set the branch to main and the folder to /(root).

Your site will be live at https://[your-username].github.io/[repo-name]/.
